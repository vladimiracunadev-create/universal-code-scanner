# Catálogo de regresión visual

Los archivos de este directorio tienen resultados esperados en `manifest.json`. Los QR se generaron de forma determinista y sirven para pruebas de cámara e integración. Las carpetas de otras simbologías quedan reservadas para capturas reales verificadas; no se inventan muestras que puedan entregar falsos positivos.

Escenarios incluidos: contenido web, Wi-Fi, contacto, GS1 textual, daño parcial, iluminación baja, deformación controlada y múltiples códigos en una imagen.

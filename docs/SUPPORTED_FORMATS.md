# Formatos y contenidos

## Simbologías de lectura solicitadas al motor

- QR Code y Micro QR.
- Data Matrix.
- Aztec.
- PDF417.
- MaxiCode.
- Code 128, Code 39 y Code 93.
- Codabar.
- EAN-13 y EAN-8.
- UPC-A y UPC-E.
- ITF y variantes expuestas por la plataforma.
- GS1 DataBar, Expanded y Limited cuando el backend lo admite.

La compatibilidad exacta depende de Android ML Kit, Apple Vision o el backend web activo.

## Contenidos interpretados

- URL, texto y binario.
- Wi-Fi, vCard, MeCard, evento, correo, teléfono, SMS y geo.
- OTP.
- GS1 Application Identifiers.
- ISBN y producto.
- EMVCo, EPC/SEPA, Swiss QR.
- Bitcoin, Lightning y Ethereum.
- AAMVA/PDF417 reconocible.

## Generación

- QR, Data Matrix, Aztec, PDF417.
- Code 128, Code 39, EAN-13, EAN-8, UPC-A y GS1-128.

## Fuera del alcance garantizado

rMQR, DotCode, códigos privados, cargas cifradas y documentos de identidad sin especificación pública requieren motores o parsers adicionales.
